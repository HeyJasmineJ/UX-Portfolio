# Jasmine Wilson — portfolio

Personal site for jasminewilson.com. Static HTML, CSS, and a little JavaScript.

```bash
npm start
```

http://localhost:3000/

Edit copy and structure in `scripts/render_site.py`, then run `python3 scripts/render_site.py`. Styles live in `css/site.css`. Behavior (mobile nav, contact mailto, image lightbox) lives in `js/site.js`.
